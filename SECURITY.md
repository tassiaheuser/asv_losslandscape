# Security policy

Please report suspected vulnerabilities privately through GitHub's security-advisory interface
rather than a public issue. Include affected files, reproduction steps, and potential impact.

Never attach dataset credentials, private dataset files, checkpoints with restricted terms, or
personal data to a report. Automated authenticated VoxCeleb downloads are deliberately unsupported;
obtain data through the official access workflow. Public augmentation downloads must use verified
HTTPS and are protected by regression tests against insecure transport options.
